cookies.txt file In use

How to get cookies.txt

  1. In your browser, install the extension "Get cookies.txt LOCALLY".
  2. Open youtube.com and make sure you are signed in.
  3. Click the extension, then Export. It saves a .txt file.
  4. Choose that file above and click Use this file.

Keep this file private. Anyone who has it can use your YouTube account. Export a new one when downloads start asking for sign-in again.

Sign in to YouTube?

To download age-restricted videos, this app needs to use your YouTube sign-in.

  • Google's own sign-in page opens in a new window. You type your password into Google. This app never sees your password.
  • After you sign in, the app saves your YouTube sign-in cookies in a file on this PC only: {{ cookie_path }}
  • The app uses them only to download videos from YouTube. They are never sent anywhere else.
  • Anyone who gets that file can use your YouTube account. Do not share it.
  • You can click Sign out at any time to delete it.
